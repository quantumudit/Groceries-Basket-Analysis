# Contributing to Groceries Basket Analysis

This is a solo project, but if you find an issue or have suggestions, feel free to open an issue or pull request.

## Setup for Local Development

1. Fork and clone the repo
2. Create a new branch: `git checkout -b fix/your-feature-name`
3. Make your changes and commit with a clear message
4. Push and open a pull request

## Commit Message Guidelines

Follow [Conventional Commits](https://www.conventionalcommits.org/):

Examples:
- `feat: add new analysis module`
- `fix: correct null handling in preprocessing`
- `docs: update README with result description`

Thanks for checking out the project!
